A token launch radar: every pre-token DeFi protocol ranked by an implied value derived from the snapshot's own figures (TVL, 7-day growth, age with no token, category strength, chain reach), each with a concrete farm plan. Built by an AI agent for make.fun's "Build the best token launch radar" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```
